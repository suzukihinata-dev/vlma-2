# R3（学習）に向けた準備メモ

R3: 作った前提と操作、図を使ってモデルを学習することが出来る（REQUIREMENTS.md）。2026-10-07 時点の調査結果。

## モデル: Qwen3.5-0.8B（ユーザー確認済み）
Hugging Face の公開情報（[Qwen/Qwen3.5-0.8B](https://huggingface.co/Qwen/Qwen3.5-0.8B)、[Qwen/Qwen3.5-0.8B-Base](https://huggingface.co/Qwen/Qwen3.5-0.8B-Base)、[transformers の解説](https://huggingface.co/docs/transformers/en/model_doc/qwen3_5)）と、WNPC にダウンロードした設定ファイルで確認した。
- 画像と文章を入力できる（視覚エンコーダーつきの言語モデル。`Qwen3_5ForConditionalGeneration`）。パラメータ数 0.8B、ライセンス Apache 2.0、コンテキスト長は 262,144。
- 構造は、Gated DeltaNet（線形注意）3層と、通常の注意機構1層の繰り返し。
- 事前学習のままの `Qwen3.5-0.8B-Base` と、追加の学習を受けた `Qwen3.5-0.8B` がある。要件は「継続事前学習」なので、Base から始めるのが自然（私の推奨。**未決**）。
- 画像: パッチ 16、2×2 をまとめるので、トークン1個が 32×32 ピクセル。512×512 の画像は 256 トークン（処理の設定 `size` は最小 65,536、最大 16,777,216 ピクセルで、512×512 は拡大・縮小されない）。
- トークナイザー: `Qwen2TokenizerFast`、語彙数 248,077。

## 学習の環境（WNPC）で足りないもの
- 既存の `genesisgeo-model` のイメージは、Python 3.10.19、torch 2.8.0+cu128、`transformers` 4.57.6。**`transformers` に `qwen3_5` が無い**（解説は v5.x）。新しい学習用のイメージが要る。
- Gated DeltaNet の高速化の部品（`fla`、`causal_conv1d`）は、未導入。解説には、一部の最新 GPU（GB10 など）では、ビルドが無く、遅い PyTorch の代替処理に落ちるとある。WNPC の GPU は RTX PRO 4500 Blackwell（32GB）で、同じ問題が起きる可能性がある。**試す必要がある**。
- `peft`、`trl`、`datasets`、`deepspeed`、`flash_attn` も未導入（必要かどうかは、学習方法による）。

## サンプルのトークン数（`scripts/r2_token_lengths.py`、先頭1,500問・86,072サンプル）
並べ方（仮）: 画像 + 問題・目標・情報・過去の操作列 → 出力。
| 項目 | 中央値 | 90%点 | 最大 |
|---|---|---|---|
| 出力（1手） | 32 | （99%点 107） | 197 |
| 情報欄 | 656 | 1,362 | 2,384 |
| 過去の操作列 | 1,026 | 3,290 | 7,193 |
| 問題文と目標 | 142 | | 313 |
| 合計（画像256トークンを含む） | 2,147 | 5,118 | 10,164 |
- 合計が 2,048 を超えるサンプルは52%、4,096 を超えるのは19.8%、8,192 を超えるのは0.4%。コンテキストを8,192にすれば99.6%が入り、16,384ならすべて入る。
- 長い入力は、情報欄（数値）と過去の操作列が占める。情報欄は、数値1つが数トークンになるため、文字数のわりにトークンが多い。
